# Project 십이지

## 유니티 게임 프로젝트
with PandoraCube Sejong Univ.


- 각 레벨에는 정비 페이즈, 전투 페이즈가 존재합니다.

## 정비 페이즈
- 크레딧을 소모해 상점에서 기물, 아이템을 구매할 수 있습니다.
- 구매한 기물을 필드에 배치할 수 있습니다. 
- 필드에 아군 기물을 최대 12개 배치할 수 있습니다.
- 전투를 진행한 기물은 이후 정비에서 이동할 수 없습니다.
- 동일한 기물을 드래그해 강화할 수 있습니다.
- 일부 아이템은 정비 페이즈에서만 사용할 수 있습니다.

## 전투 페이즈
- 본인 턴 시작 시 행동 카운트 3을 제공합니다.
- 기물을 이동하면 행동 카운트를 1 소모합니다.
- 기물 정보창의 스킬 사용을 눌러 스킬을 사용할 수 있습니다. 행동 카운트를 1 소모합니다.
- 인벤토리의 아이템을 눌러 아이템을 사용할 수 있습니다. 행동 카운트를 1 소모합니다.
- 본인 턴이 종료되면, 모든 아군 기물이 각각 1회 공격합니다.

## 기물 스킬
### 기본 기물
- 폰 : 아군 기물을 선택합니다. 해당 기물과 동일한 기물로 변신합니다. 레벨은 기존 레벨이 유지됩니다.
- 봄버 : 기물 주변 2칸 이내 모든 기물에 현재 체력만큼 피해를 입힙니다. 이후 자신은 체력이 1이 됩니다.
- 비숍 : 기물 주변 2칸 이내 아군 기물에 공격력*2만큼 체력을 회복시킵니다.
- 아처 : 적군 기물을 선택합니다. 해당 기물에 공격력만큼 피해를 입히고, 방어력을 1 감소시킵니다.
- 탱크 : 기물 주변 1칸 이내 적 기물의 공격력을 1 감소시킵니다.
- 캐논 : 공격범위 내 적 및 적 주변 1칸 이내 적 기물에 공격력만큼 피해를 입히고, 방어력을 1 감소시킵니다.
- 나이트 : 기물 주변 1칸 이내 아군 기물의 마나를 2 회복시킵니다.
- 룩 : 아군 기물을 선택합니다. 해당 기물과 자리를 바꾸고 방어력을 1 증가시킵니다.
- 타워 : 공격범위 내 타일을 선택합니다. 해당 위치에 아군 폰을 소환합니다. 해당 기물은 행동할 수 없습니다.
### 고급 기물
- 유니콘 : 모든 유니콘이 공격을 1회 실행합니다. 이후 아군 나이트 1개가 유니콘으로 변화합니다. 레벨은 나이트의 레벨을 유지합니다.
- 퀸 : 기물 주변 2칸 이내 아군 기물의 공격력을 1 증가시킵니다.
- 킹 : 기물 주변 1칸 이내 적 기물에 소모한 마나 * 공격력만큼의 피해를 입힙니다.

## 아이템 스킬
### 정비 아이템
- 강화 : 기물을 선택합니다. 기물의 레벨이 영구히 1 증가합니다.
- 재설정 : 기물을 선택합니다. 기물이 해당 정비 페이즈동안 이동할 수 있습니다.
### 전투 아이템
- 아드레날린 : 모든 기물의 공격력을 1 증가시키고 방어력을 1 감소시킵니다.
- 기습 : 기물을 선택합니다. 기물이 즉시 1회 공격을 실행합니다.
- 부식 : 기물을 선택합니다. 기물의 방어력을 2 감소시킵니다.
- 최적화 : 기물을 선택합니다. 기물의 최대 마나를 1 감소시킵니다.
- 마나 물약 : 기물을 선택합니다. 기물의 마나를 최대로 회복시킵니다.
- 낙뢰 : 모든 기물에 최대체력의 25%에 해당하는 피해를 입힙니다.(피해는 내림적용)
- 과부하 : 기물을 선택합니다. 해당 기물의 스킬을 즉시 발동합니다.(스킬 대상은 랜덤 선택)
- 체력 물약 : 기물을 선택합니다. 기물의 체력을 최대로 회복시킵니다.
- 보호 : 기물을 선택합니다. 기물의 방어력을 2 증가시킵니다.
- 워프 : 기물을 선택합니다. 이후 타일을 선택합니다. 기물을 해당 위치로 이동시킵니다.
